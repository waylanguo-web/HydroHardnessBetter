# HydroHardnessBetter

Hydro 插件：题目创建、编辑的难度支持 800–4000 整数，在题单、题目详情、侧栏和训练中按指定 RGB 显示。空值和历史 1–10 难度显示为未评级（—），不自动猜测或迁移历史难度。

颜色依次为：800–899 `254,76,97`；900–1199 `243,156,17`；1200–1599 `255,193,22`；1600–1999 `83,196,26`；2000–2399 `19,194,194`；2400–2699 `52,152,219`；2700–3099 `156,61,207`；3100–4000 `14,29,105`。

## 安装

将仓库放到插件目录，将其绝对路径追加到 `~/.hydro/addon.json` 数组末尾，重启 Hydro。插件依赖默认 UI 的 template 服务，不需要构建步骤。卸载时移除数组中的路径并重启。建议先备份 addon.json。

运行 `npm test` 进行基础测试。插件调整 Hydro 的参数装饰器元数据，并在原有模板上替换难度展示，保留原有权限校验；若 Hydro 改变内部接口，需要重新验证兼容性。未改动数据库中的历史数值或 RP 计算规则；若站点启用基于题目难度的 RP 计算，需单独评估新量纲。
